

\# E-commerce Sales \& Customer Analysis Using SQL



Project Type: Data Analyst Portfolio Project

Database: SQLite

Tool: DB Browser for SQLite

Dataset: Simulated E-commerce Data



\## Project Objective

The objective of this project is to analyze e-commerce

sales and customer behavior using SQL queries.



The analysis focuses on:

1\. Sales revenue and completed orders

2\. Product and category performance

3\. Customer purchasing behavior

4\. Order status distribution

5\. Sales transaction patterns



\## Database Tables

\- customers

\- products

\- orders

\- order\_items



\## Data Note

This project uses simulated data for educational

and portfolio purposes. It does not represent

real company transactions.





\## Project Status



Core SQL analysis completed:

\- Database table exploration and record counts

\- Completed-order revenue analysis

\- Revenue by product

\- Order status distribution

\- Customer spending analysis

\- Customer order frequency

\- Average units per completed order



\## Key Findings from Simulated Data

\- Completed orders: 9

\- Completed revenue: 3,265,000 currency units

\- Highest-revenue product: Mechanical Keyboard

\- Revenue from highest-revenue product: 900,000 currency units

\- Highest-spending customer: Andi Pratama

\- Highest-spending customer total: 865,000 currency units

\- Average units per completed order: 2.33

\## Limitations

The dataset is simulated and relatively small.

The currency unit has not been verified.

The findings should not be generalized to

real-world e-commerce businesses.
